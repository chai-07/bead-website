# 2026-11-08

## Bug fix: 手机端顶部「网格/草稿/导出」下拉无反应
- 根因：`css/mobile.css` 中 `.mt-drop` 只有 `display:none`，缺少 `.mt-drop.open` 的显示规则；JS（ui.js 顶部下拉 click 处理）已正确给下拉加 `open` 类，但无样式使其可见，故点击无效。底部级联菜单能用是因为有 `.cascade.open{display:flex}`。
- 修复：在 mobile.css 增加 `.mt-drop.open{display:block}`，并加 `.mt-drop .control-group{...}` 将内部 control-group 去除嵌套边框/背景、改为纵向 flex，使下拉面板更干净。
- 三类按钮（data-dd=grid/draft/export）共用此下拉，修复后三者均生效。

## Bug fix: 手机端导出按钮（下载效果图/色号图纸/一键打包）点了没反应
- 根因：导出走 programmatic `<a download>.click()`。PNG 用 `canvas.toDataURL` 生成超大数据 URL；在 iOS Safari / 微信等 webview 中，对 data/blob URL 的程序化下载常被静默拦截，且原代码无任何反馈，表现即“点了没反应”。
- 修复：
  - `js/render.js` 的 `downloadResult`/`downloadCodeResult`：改用 `canvas.toBlob` 取 blob（避免巨型 data URL 在移动端崩溃/失败），并在 toBlob 失败时退回 dataURL。
  - `js/export.js` 的 `downloadBlob` 增强：先 append 到 body 再 click；识别 iOS/微信等 webview 时，延时 `window.open` 新标签供长按保存；延长 revoke 时间。新增 `toast()` 用 `#pixelInfo` 给出“已开始下载…”可见反馈（含长按保存提示）。
  - `downloadColorPdf`/`downloadCsv`/`packageExport` 一并改用新 `downloadBlob` 并加 toast。
- 注意：ZIP/CSV 在微信 webview 内仍可能受限，已用 toast 提示用户改用桌面版/浏览器。

## Bug 4 (02:46) 导入 .json 草稿后「彩色PDF / CSV耗材清单 / 一键打包导出(4种)」三个按钮点不了
- 根因：`js/draft.js` 的 `applyGrid()`（导入/读取草稿时调用）只解禁了 `downloadBtn` 和 `downloadCodeBtn`，漏掉了 `colorPdfBtn / csvBtn / packageBtn`，这三个按钮一直保持 `disabled`（灰显）。而正常生成走 `render.js` 的 `process()` 会解禁全部 5 个。手机端导出下拉 `#dd-export` 通过 `MB_mount` 移动的是同一批 DOM 元素（非克隆），所以改原节点即可同时修复手机下拉。
- 修复：`applyGrid()` 内补上 `colorPdfBtn/csvBtn/packageBtn` 的 `disabled=false`。
- 验证：导入 .json 草稿后，底部/导出下拉的彩色PDF、CSV、打包三个按钮应变为可点击（不再灰显）。

## Bug fix: 手机端工艺评审报告——标签页(问题概览/问题详情/整改界面)被“工艺评审报告”表头挡住
- 根因：`.review-panel`(overflow:auto) 与 `.rp-body`(继承自桌面样式 overflow-y:auto) 形成双重滚动；`.rp-header` 是 position:sticky(z-index:5, 不透明背景) 且紧贴 `.rp-body` 内的标签页行（buildReview 中第一个 div）。双重 sticky + 滚动使表头遮挡了下面的三个标签页，且原本 mobile 下 `.sheet-grip` 是 display:none。
- 修复（css/mobile.css，两个等价块 body:not(.force-desktop) 与 body.layout-mobile 均改）：
  - 单一滚动容器：`.rp-body` 改为 `flex:0 0 auto; overflow:visible`，由面板整体滚动，去掉内部滚动。
  - `.rp-header` 固定高度 `height:calc(42*var(--m-scale)); align-items:center`（确定性高度），sticky top:30（在 grip 30 之下）。
  - 标签页行(`.rp-body>div:first-child`)设为 `position:sticky; top:calc(72*var(--m-scale)); background:#16181d; z-index:4`，始终吸附在表头正下方，不再被遮挡。
  - 让 mobile 下 `.sheet-grip` 显示(display:flex)，恢复关闭按钮与 top:30 布局意图。
- 桌面端(force-desktop)未受影响。
