## 拼豆图纸生成器 index.html — 增加版本选择器 + 修复手机端排版
- 需求：PC 端排版 OK，手机端乱；希望进入网站时可选择 电脑版 / 手机版。
- 做法（单文件 index.html，未拆文件以免维护两份）：
  1. 新增进入版选择器 `#versionChooser`（全屏遮罩，💻电脑版 / 📱手机版 两张卡片），可勾选"记住我的选择"存入 localStorage（key: bead_version / bead_version_remember）；右下角 `#switchVersionBtn` 随时切换。
  2. 统一布局判定函数 `isMobileLayout()`（替代原 `window.innerWidth<1200` 散落判断），让"手机上强制桌面"不与抽屉逻辑冲突；`openReview`/`scheduleReview` 已改用它。
  3. 强制桌面模式：`body.force-desktop` 用 !important 覆盖响应式样式，并给中间列 `min-width:480px` 让窄屏横向滚动呈现完整桌面。
  4. 手机版排版优化（@media max-width:1200px）：`.mid-bottom` 工具条改为可横向滑动（不再 nowrap 挤爆）；画布 `max-width:100%` 自适应宽度；标题允许换行；原图浮窗避让底部工具条。
- 校验：抽取 <script> 用 new Function 语法检查通过。
- 注意：改动仅在本地 index.html，GitHub Pages 需重新 push 才生效（线上仍为旧版）。
