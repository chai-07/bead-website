## 桌面抽屉 px→等比缩放（同日晚）
用户满意桌面版在自家屏上的观感，但其它设备写死 px 比例会失真。已把桌面抽屉（左控制面板/右评审面板/原图浮窗）及其内部字号·内边距·间距从写死 px 改为 `calc(N * var(--d-scale))`：
- `:root` 新增 `--d-scale: clamp(0.55px, min(calc(100vw/1280), calc(100vh/800)), 1.8px)`。基准=**1280×800 CSS 像素**（用户物理屏 2560×1600 但**系统开 200% 缩放**，浏览器视口≈1280×800；CSS 的 vw/vh 按 CSS 像素算，故基准必须用 CSS 像素而非物理分辨率，否则会被算成一半大）。该视口下因子=1，面板=400px，与改造前固定 px 观感完全一致。
- 改动只在 `css/style.css`（桌面基础规则 + `body.force-desktop` 块的侧栏 width/min-width/padding-top）。手机端 `mobile.css` 本就用 vh/vw 不动；画布中间区（preview/result/mid-bottom）与移动端 media 块保持原 px，不属于抽屉。
- 验证：括号 148/148 平衡，39 处 `var(--d-scale)` 引用；剩余硬编码 px 均为中间区/移动 media/发光阴影，符合预期。
- 已同步更新 README「二次开发约定」：说明基准修改点、改宽度锚定/调 clamp 上下限的方法，并强调基准要用 CSS 像素视口（系统缩放 200% 时物理分辨率 ÷2）。
- 注意：`min()` 内除法已包 `calc()` 以防老引擎。若用户实际浏览器窗口高度≠800（有浏览器chrome），在该屏会按较小边微缩，非完全等于旧 400px——可把 800 改成其真实 innerHeight 或改用纯 vw 锚定。
