# 2026-11-03 工作日志

## 拼豆网站 index.html — 修正手机版"左右控制栏看不见"
- 用户反馈：手机版主要问题是左（设置）右（评审）两个控制栏在手机上根本不显示。
- 根因：原 `@media(max-width:1200px)` 把这两个面板做成"移出屏幕的隐藏抽屉"（默认 transform:translateX(±105%)），需点 ☰/📋 才滑出；用户没意识到，以为坏了。
- 改法（保留单文件）：
  1. 手机版改为**顶部三视图切换栏**（🎨设置 / 🔮画布 / 📋评审），三个面板各自作为整屏视图（`body:not(.force-desktop).mv-*` / `body.layout-mobile.mv-*` 控制 display），点哪个显示哪个——左/右栏在手机上一定可见。
  2. 新增 `showMobileView(view)` 统一切换；`applyVersion('mobile')` 默认进画布视图；顶部 tab 按钮（含新增 #showCanvas）绑定切换。
  3. 重写 `openSettings`/`openReview` 改为调用 `showMobileView`（旧抽屉逻辑废弃）。
  4. 抽屉式 `.control-panel/.review-panel` 的 transform/固定定位在手机端被 `position:static;transform:none;display` 规则覆盖；scrim 在手机端隐藏。
- 校验：抽取 <script> 用 new Function 语法检查通过。
- 注意：GitHub Pages 需重新 push 才上线；本地双击 index.html 可测。

## 二次修正 — 改成"美图秀秀式"手机竖屏排版（用户明确要瘦长屏、画布为主角）
- 用户反馈：之前的"顶部三视图整屏切换"不对，手机是瘦长屏，应像修图 App（美图秀秀）那样排版。
- 最终方案（单文件，保留电脑版/手机版选择器）：
  1. **画布占主角**：手机端 `app-container` 高度 100vh、overflow hidden；`center-column` 竖排，画布 `result-area` 占满剩余高度并居中自适应宽度（`canvas{max-width:100%}`），`mid-bottom` 工具条常驻在画布正下方、可横向滑动。
  2. **底部图标工具栏** `#mobileBar`（固定在底部，不再在顶部）：🎨设置 / 🛠️工具 / 📋评审 三个图标按钮。
  3. **设置/评审改为底部上滑半屏 sheet**：`.control-panel/.review-panel` 在手机端 `position:fixed;bottom:0;transform:translateY(100%)`，`.open` 时 `translateY(0)` 从底部滑出（max-height:84vh、圆角、顶部手柄条 ::before、安全区 padding）。复用桌面端 scrim 遮罩（z-index 72，点按关闭）。
  4. 交互：`openSheet(name)` 打开底部面板并高亮对应底部按钮；`closeSheet()` 关闭并清高亮；底部"工具"按钮 `body.mb-hidden` 切换折叠画布下方工具条；再点已打开的按钮可收起；点 scrim 关闭（监听由 closeAll 改为 closeSheet）。
  5. 删除旧 `showMobileView`/`mv-*` 整屏逻辑与 `data-view`，改 `data-sheet`；版本选择卡片文案更新为"画布为主角 · 底部工具栏 · 弹出式面板"。
  6. `force-desktop`（手机上强制电脑版）与 `layout-mobile`（宽屏强制手机版）两套规则同步重写为上述竖屏布局。
- 校验：抽取 <script> 语法检查通过；grep 确认无残留 showMobileView/mv-*/data-view。
- 真机测试建议：本地双击 index.html，选"手机版"，看画布是否占主体、底部工具栏、点设置/评审是否从底部弹出。

## 三次修正 — 按用户参考图重排为"修图App式"手机排版
- 用户给了一张醒图/美图类修图App截图，要求手机版：底部一栏是电脑版左栏那些功能；右上角集合草稿+四种导出按钮（弹窗）；撤回/缩放放画布下；网格/色号放顶上；评审放顶上做浮窗。
- 改动（单文件 index.html）：
  1. **给每个功能组打 `data-grp`**：control-panel 内 上传/裁剪/画布/色板/调色/增强/清理/对称/手动/挂件/智能 共11组加 `data-grp`；导出块（命名前缀+5个下载按钮）包成 `data-grp="export"` 的 control-group；mid-bottom 内 网格/色号/草稿 也加 `data-grp`（手机端隐藏，移顶部/右上角）。
  2. **顶部栏 `.mobile-top`**（手机端 fixed top）：左 `🔲网格` `🔢色号` `📋评审`，右 `📂草稿` `💾导出`（accent 高亮）。网格/色号点按同步原 `#showGrid`/`#showColorCodes` 控件并重绘；评审点开为顶部浮窗；草稿/导出点开底部弹出对应组。
  3. **底部功能分类 tab `.mobile-bar`**：横滑一排图标（上传/裁剪/画布/色板/调色/增强/清理/对称/手动/挂件/智能），点哪个从底部弹出该组参数面板（`openSheet('settings', grp)` 按 data-grp 过滤显示）。
  4. **评审改为顶部滑下浮窗**：review-panel 手机端 `top:0;transform:translateY(-100%)` → `.open` 下滑；control-panel 仍为底部 sheet；z-index：scrim 70 / sheet 74 / mobile-top 75 / mobile-bar 78（底部tab始终最上，sheet底部留白72px避开）。
  5. **画布下操作条**：mid-bottom 在手机端隐藏 网格/色号/草稿 组后，只剩 原图/缩放/撤回重做，正好满足"撤回放画布下、缩放放旁边"。
  6. JS：`openSheet(name,grp)` 按组过滤+高亮；`closeSheet()` 清除 inline 显隐并清高亮；`applyVersion` 切版本时恢复所有 group 显示；顶部/底部按钮绑定；顶部开关同步原控件（网格 dispatch change 重绘，色号调 toggleColorCodes）。
  7. 删除旧 `data-sheet`/三按钮逻辑，改 `data-grp`；`force-desktop`/`layout-mobile` 两套规则同步。
- 校验：抽取 <script> 语法检查通过；grep 确认无残留 data-sheet/dataset.sheet。
